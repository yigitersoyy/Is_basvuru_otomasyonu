# Job Application and Outreach Automation

Detailed architecture for a personal job application and outreach system using self-hosted n8n, Appsmith, Ollama, PostgreSQL, Gotenberg and Gmail.

## Architecture plan

- [English architecture plan (Markdown)](docs/Job_Application_Outreach_Architecture_EN.md)
- [English architecture plan (PDF)](docs/Job_Application_Outreach_Architecture_EN.pdf)
- [English architecture plan (Word)](docs/Job_Application_Outreach_Architecture_EN.docx)

The plan covers CV tailoring, company and vacancy research, professional contact discovery, personalized outreach, reply tracking, follow-ups, deployment, recovery and acceptance tests.

**Status:** Planning complete. Implementation has not started.

Designed for Windows 11, 32 GB RAM and an RTX 4060, with local inference and no required software subscriptions or paid LLM APIs. Existing hardware, electricity, internet and email-provider limits still apply.
